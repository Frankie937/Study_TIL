## 6개 유용한 skill 정리 (from Jay Choi | 인디해커 라이프)
*  영상: https://www.youtube.com/watch?v=UClLUoGaCxU
### 1) Karpathy Guidelines (0:34): AI 코딩 시 발생하는 흔한 문제들(무작정 구현 시작, 불필요하게 긴 코드 등)을 방지하기 위한 가이드라인입니다. 마크다운 파일 하나로 프로젝트 전체에 규칙을 강제할 수 있습니다.
* andrej-karparthy-skills
  * /plugin marketplace add forrestchang/andrej-karpathy-skills
  * /plugin install andrej-karpathy-skills@karpathy-skills

### 2) claude-video (1:58): 클로드가 유튜브 영상의 화면과 음성을 직접 분석하게 해줍니다. 영상의 구조 분석이나 대본 작업 시 매우 유용합니다.'
* claude-video 
  * /plugin marketplace add bradautomates/claude-video
  * /plugin install watch@claude-video
    
### 3) Superpowers (3:20): 클로드에게 '시니어 개발자 프로세스'를 강제하는 스킬입니다. 코드 작성 전 스펙 정리와 테스트 코드 작성을 필수로 만들며, 코드 품질을 대폭 향상시킵니다.
⁠* superpowers
  * /plugin install superpowers@claude-plugins-official

### 4) Understand-Anything (4:50): 방대한 코드 베이스를 분석하여 지식 그래프로 시각화해 줍니다. 복잡한 프로젝트 구조를 파악할 때 유용합니다.
* Understand-Anything
  * /plugin marketplace add Egonex-AI/Understand-Anything
  * /plugin install understand-anything

### 5) agentmemory (6:15): 세션이 바뀌어도 프로젝트 맥락을 기억하게 해주는 메모리 스킬입니다. 벡터 및 그래프 검색을 통해 필요한 정보만 효율적으로 불러옵니다.
* agentmemory
  * npx @agentmemory/agentmemory
  * agentmemeory
    
### 6) Skill Creator (7:26): 사용자의 작업 방식에 최적화된 맞춤형 스킬을 직접 생성해 줍니다. 반복적인 프롬프트를 스킬화하여 재사용하면 작업 속도가 훨씬 빨라집니다.
